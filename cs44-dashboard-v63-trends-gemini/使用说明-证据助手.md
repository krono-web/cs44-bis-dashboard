# CS-44 证据助手与免费 API 部署

## 页面功能

原文检索无需 API，可按年份、课程、UG/PG、教学类别、证据状态和大纲章节查询。结果直接展示保存的原文、命中词、规则、分数及来源链接。中文或英文语法不完整时，只要能识别课程代码、类别别名或原文关键词，通常仍能检索；它不是完整的自然语言理解系统。

可选 AI 模式使用 Gemini Developer API，对检索结果进行说明。后端最多发送 24 条匹配证据和完整统计值；模型必须返回结构化 JSON，并引用已提供的证据 ID。后端会拒绝无效引用。没有匹配时不会调用模型。

## 免费部署方案

网站继续放在 GitHub Pages；`cloudflare-worker/` 部署为 Cloudflare Worker；模型使用 Gemini 免费层。免费层有配额限制，Google 说明免费层提交的内容可用于改进产品，因此本项目只应发送公开课程大纲证据，不要输入个人或机密资料。

1. 在 Google AI Studio 建立 Gemini API key。
2. 安装 Node.js，在 `cloudflare-worker/` 执行 `npm install`。
3. 登录 Cloudflare：`npx wrangler login`。
4. 添加两个密钥：

```powershell
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put ASSISTANT_ACCESS_TOKEN
```

`ASSISTANT_ACCESS_TOKEN` 是你自己设置的课堂访问码，建议至少 16 个随机字符；它不是 Gemini key。

5. 检查 `wrangler.jsonc` 中的 `ALLOWED_ORIGINS`。当前已设为 `https://huaicongyu-stack.github.io`。
6. 发布：`npm run deploy`。
7. 把返回的 Worker HTTPS 地址填入 `dashboard/assistant-config.js`：

```js
window.CS44_ASSISTANT_API = "https://你的-worker.workers.dev";
```

8. 将 `dashboard/` 全部文件提交到实际驱动 GitHub Pages 的仓库。

Gemini API key 只存于 Worker secret，不能写进 GitHub Pages、JavaScript、Git 仓库或截图。页面只要求普通访问码，用于避免任何访客消耗免费额度。若要公开给大量用户，应再增加 Cloudflare Rate Limiting 或真正的登录系统。

## 更新数据

修改历史数据后运行：

```powershell
python history-source/build.py
node history-source/export_worker_data.cjs
```

第二条命令会刷新 Worker 内置的 `datasets.json`，确保 AI 检索与页面数据一致。

## 解释限制

Positive 是自动规则产生的正向信号，Review-only 不能单独证明分类成立。缺少大纲与零匹配不同；一句原文可能进入多个类别。模型引用校验能防止引用不存在的记录，但不能保证每句解释都正确，最终应打开来源原文核对。
